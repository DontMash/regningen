# Triage Labels

Map canonical triage roles to the strings used in this repo's issue tracker.
For local markdown issues, these strings are recorded in the `Status:` line.

| Canonical role    | Tracker string    | Meaning                                  |
| ----------------- | ----------------- | ---------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate this issue  |
| `needs-info`      | `needs-info`      | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent  |
| `ready-for-human` | `ready-for-human` | Requires human implementation            |
| `wontfix`         | `wontfix`         | Will not be actioned                     |

When a skill mentions a triage role, use its corresponding tracker string.
Edit the "Tracker string" column to change the vocabulary.
